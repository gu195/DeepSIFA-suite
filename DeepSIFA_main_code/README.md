# DeepSIFA main code

This directory is the complete main MonoXtract research directory supplied for
public release. It contains trace extraction, preprocessing, inference,
checkpoints, MATLAB routines, example data, generated results, DLRunner, and
legacy auxiliary analyses.

Main entry points:

```bash
python sample.py --help
cd DeepSIFA
python eval_test.py --help
```

`sample.py` requires MATLAB Engine for Python. Neural-network evaluation of
already processed traces does not require MATLAB.
